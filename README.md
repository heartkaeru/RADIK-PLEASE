# RADIK, PLEASE!

**RADIK, PLEASE!** — это 2D-игра, вдохновленная культовой "Papers, Please", но в университетском сеттинге. Игроку предстоит взять на себя роль охранника в учебном заведении. Ваша задача — проверять документы посетителей (студенческие билеты, удостоверения преподавателей) и принимать решения: пропустить человека или отказать ему в доступе, опираясь на правила, которые меняются и усложняются с каждым днем.

## Особенности игры

* **Система проверки документов:** Внимательно изучайте даты выдачи и рождения, форматы групп (соответствие институтов и направлений), уровни и формы обучения, должности преподавателей.
* **Прогрессия сложности:** Каждый новый день добавляет новые правила и проверки (начиная от простого наличия документа, заканчивая выявлением поддельных удостоверений).
* **Экономика:** За правильные решения вы получаете деньги, за ошибки — штрафы. Уйдете в минус — вас уволят!
* **Генетический алгоритм генерации:** Игра использует `GeneticDayPlanner` для умной генерации потока посетителей с нужным балансом "чистых" и "проблемных" документов.
* **Настройки:** Поддержка изменения громкости музыки/звуков.
* **Сохранения:** Прогресс сохраняется автоматически, вы можете прервать игру и продолжить с того же места.

## Архитектура проекта

Код написан на языке Python с использованием библиотеки **Pygame** и строго следует паттерну **MVC (Model-View-Controller)**:

* `main.py` — Точка входа, инициализация и запуск `GameController`.
* `model.py` (Model) — Ядро игровой логики. Включает генерацию персонажей (`PersonGenerator`), правила игры (`GameRules`), проверку документов (`Checker`), экономику (`Economy`) и генетический планировщик дня.
* `view.py` (View) — Модуль рендеринга. Отвечает за отрисовку всех экранов (меню, игра, итоги дня, настройки), анимацию персонажей и отображение UI (кнопки, слайдеры, документы).
* `controller.py` (Controller) — Связывает модель и представление. Обрабатывает ввод пользователя (клики, мышь), управляет состояниями игры, сохранением/загрузкой и музыкой.
* `config.py` — Хранилище всех констант проекта: тексты, цвета, размеры, шансы генерации, имена, названия институтов и кафедр, пути к ассетам.

## Требования

* Python 3.8+
* Pygame 2.5.2

## Установка и запуск

1. Убедитесь, что у вас установлен Python.
2. Установите зависимости из `requirements.txt`:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустите игру:
   ```bash
   python main.py
   ```

## Структура директорий

* `assets/` — содержит все медиафайлы (изображения, звуки, музыка). Разделен на поддиректории:
  * `images/` — фоны, UI-элементы, спрайты персонажей (`male/`, `female/`, `professor/`).
  * `sounds/` — аудиофайлы и фоновая музыка.
* `tests/` — тесты для проверки игровой логики.

## Как играть

1. В начале каждого рабочего дня кликните по инструкции на столе, чтобы ознакомиться с правилами пропуска на сегодня.
2. Когда подойдет посетитель, проверьте его документ (если он есть). Нажмите на документ на столе, чтобы приблизить его.
3. Сравните данные в документе с актуальной инструкцией (соответствие института и префикса группы, правильная дата выдачи и т.д.).
4. Примите решение, нажав на зеленую кнопку 'Пропустить' или красную 'Отказать'.
5. Постарайтесь не допускать ошибок, чтобы заработать как можно больше денег и перейти на следующий день.
